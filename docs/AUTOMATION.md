# 全自动制作

把小说原文或视频需求写清楚，选择集数、时长和画面比例，然后勾选 **全自动完成 · 不设费用上限** 并开始。已有项目也可以点击同名入口。开启后不需要逐步批准规范、分镜、参考图、镜头、配音和成片。

这是按项目保存的生产授权：允许使用该项目已配置的付费渠道、取消图片预计预算限制，并持续返工，不改变其他项目的付费设置。网页额度仍由平台决定；“不设费用上限”不表示供应商提供无限额度，也不表示生成免费。暂停或关闭自动制作可以停止后续请求，已提交的远端请求仍可能完成。

## 系统会依次完成什么

1. 读取全部小说章节或需求，整理制作要求和角色、场景、物品的固定设定。长文本分段处理，原文完整保留。
2. 生成全部分集和逐镜脚本，检查章节覆盖、集数、每集总时长、资产 ID 和单镜说话者。全自动补全未说明的创作细节，不等待逐项确认。
3. 建立每个资产的固定参考。默认人物需要正面、侧面、全身；场景需要全景和反向视角；产品和道具需要标准图和细节图。已有结构化参考规范继续生效。
4. 第一张参考通过逐资产检查后锁定；其他视角直接继承同一张母版。每镜带上固定参考及同集上一镜关键帧。必备视角不齐或文件重复，不能推进。
5. 先生成并检查关键帧，再生成动态视频。视频逐镜进行，下一镜还会引用上一镜实际交付片段的尾帧。
6. 对实际交付时段的**每一张解码帧**进行视觉检查；从第二帧起，把上一帧与本帧并排对照。每次还包含固定母版、参考视角、当前关键帧及前镜尾帧，检查人物、服装、物品、场景、状态与空间连续性。任一帧失败或不确定，视频不能进入合成，保持原参考并按问题重新生成。
7. 为每句对白或旁白生成独立音轨，已有猫叫和录音直接复用。检查音频可解码性与时长；略长的音轨最多以两倍速度保留音高、保留完整台词自动对齐，不能截断台词，超出可对齐范围时停止。按分镜时间线生成字幕，合成全部分集 MP4 并检查时长及字幕文件。
8. 在项目首页播放、下载每集成片；“下载全部成片与素材”包含原文、规范、分镜、参考图、关键帧、视频、音轨、字幕和任务记录。

## 一致性和声音规则

所有生成快照保存完整已批准制作 Markdown、版本和哈希、固定资产定义、参考文件、审核版本及字节哈希。人工批准由用户授权的自动检查接替，前置依赖校验始终保留。生成候选不能自动替换已锁定母版。规范和分镜修改会使旧下游失效；全自动沿用原先选中的独立参考原文件，按新规范重新检查，再补视角和镜头，不能重新设计已有身份。原参考被否决或缺失时停止。

原有三个人声音色与已选猫叫沿用；不新增定制、设计、克隆或激活音色。修改分镜保留角色声线，新增镜头重新绑定同一说话者。新角色使用系统音色或已有录音。配音账号、原音色或录音缺失时停止，不能用另一声音顶替；猫叫不能用普通话童声代替。复用已激活音色免再次设计/激活，不免新台词的 TTS 字符费。声音和回执只保存在本机私有目录。

## 返工、恢复和需要解决的问题

图片按设置的每批 1–5 次检查和定向修正，失败后自动进入下一批，不限制批数。视频失败后保持相同参考和版本自动重做；每一轮及检查意见都记录在原任务中。可恢复的故障使用递增等待重试（5 秒起，最多间隔 5 分钟），避免持续重复提交。完成的图片调用、视频候选和检查调用有持久化检查点，重启后复用。

以下情况不能靠重复生成解决，会显示具体原因：账号/Key/模型配置缺失、原参考或原声音缺失、素材与新要求不相容、接口不能携带全部参考、无法取得完整检查结果或提交结果不明。结果不明时保留原上游 ID 和回执，先查询原任务，不能盲目创建新请求。关闭界面不影响后台生产，但本机服务必须继续运行。

## 自动检查的实际边界

“必须一致”是生产放行条件，不能因为不限费用或开启自动化而跳过。视觉检查本身仍由模型判断，无法承诺零误判，也不能以测试通过证明实际画质、身份或口型绝对正确。逐帧检查覆盖全部解码帧，但检查图片会缩放到最长边 960 像素，微小细节仍可能识别错误。音频目前检查固定声线绑定、媒体和时长，没有自动语音转写/逐字对齐或口型验证。字幕按镜头时间段显示。

每镜最多同时绑定 7 个资产，所有必备视角在本地合成参考卡以保留完整引用；超出时规划器须拆镜。单镜支持 30 秒，逐帧提取最多 4000 帧，超过则拒绝而不跳帧。实际模型、账号、参考支持与声音质量须使用配置的外部服务验证。仓库中的离线测试和界面示例不属于外部模型生成结果。

## 接口与兼容

- 创建时传 `production_mode: "full", unlimited_budget: true` 自动开始；省略仍按旧版逐步模式创建。
- 已有项目 `POST /api/projects/{id}/automation`：`{enabled:true, mode:"full", unlimited_budget:true}`。缺少显式不限费用授权返回 422。
- `{enabled:false}` 关闭；`{enabled:true}` 沿用已保存模式和项目授权；`mode:"manual"` 回到旧版逐步流程并撤销全自动费用授权。
- `quality` 为内部检查任务，不属于公开手动生成阶段。项目进度包含独立的 `audio` 阶段。
- 全自动快照带 `full_auto`、`unlimited_budget` 和不含凭据的 `automation_authorization`；不会写入全局 Key 或开启其他项目付费。
- `speaker_id` 为角色 ID 或 `narrator`，对白每镜一人。角色可用 `speech_source: "recording"`；已选录音在声音配置使用 `recording_artifact_id` 指定同项目已批准音轨。
- 仍支持逐步制作、人工检查和否决结果；全自动不替代现有版本与依赖失效规则。
