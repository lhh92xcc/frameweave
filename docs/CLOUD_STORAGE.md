# 腾讯云 COS 素材存储

在 **模型与连接 → 云端存储** 配置桶名（含 APPID）、地域、长期素材前缀和 SecretId / SecretKey，可选 STS Token。凭据仅保存到忽略提交的 `.local/cloud-storage.json`，文件权限 0600，API 不回显。更换桶或地域需重新提供凭据，不向新目标沿用旧密钥。使用腾讯云官方 HTTPS 域名，不接受第三方上传端点。

## 迁移指定素材

```bash
.venv/bin/python scripts/cos_media.py plan --project 项目ID
.venv/bin/python scripts/cos_media.py upload --project 项目ID
```

默认仅选择 `reference`（选定参考）、`candidate`（待复核）、`repair`（明确返修）、`test`（动作试片）。`--states` 可缩小选择，不上传 `history` 废弃档案。`--data-dir` 指向本机数据目录，`--workers` 为 1–8。脚本**没有删除功能**，上传后保留所有本地副本。

原始素材与预览图以 SHA-256 内容地址上传到 `前缀/objects/`，随后完整读回核验大小和 SHA-256。ETag、上传返回成功和自定义哈希头不代替内容验证。相同文件复用对象；再次运行也会读回验证。完成一份就持久化其云位置，失败可续跑，不重新生成媒体或提升原审核状态。

私有 `.local/migrations/项目ID/` 保存计划、完成报告与恢复索引。索引包含所选素材的对象位置、哈希、项目原文和审核元数据，另作为 JSON 上传并完整验证。密钥不进入索引或 GitHub。未选择素材的二进制文件不属于此次迁移。

## 使用与本地空间

- 私有桶通过短时签名 GET 链接预览图片、缩略图与视频，无需公开读；视频 Range 请求由 COS 处理。SQLite 继续保存项目索引。
- 自动备份新生成素材默认关闭。启用后适用于所有项目的新生成/上传结果，仍保留本地文件。备份失败记为待重试，成功的模型任务不会因此重新提交。
- 下游生成、合成或 ZIP 需要缺少的本地文件时，会临时下载、校验，使用后清理临时副本。上传本身不会删除原文件、历史档案或旧项目。
- 生命周期读取权限不足时，检查返回 `unknown`。临时图片桶可能有过期规则；删除本地唯一副本前必须确认长期前缀不受自动过期规则影响。签名链接过期与对象删除是两件事。
- COS 存储、请求和外网流量按腾讯云账单计费。

## 接口与记录

`GET /api/storage` 返回不含凭据的配置、原始素材/预览数量、字节数和仍保留的本地原始副本数。`PUT /api/storage` 保存配置；留空密钥沿用同一目标的原值，`clear_keys` 显式清除。`POST /api/storage/test` 上传并读回小型测试对象，随后清理，并尝试只读获取生命周期规则，不修改桶规则。

素材引用 `storage`、`thumbnail_storage`、可选 `subtitle_storage` 记录桶、地域、对象键、大小、SHA-256、完整读回校验方式与时间，不保存 SecretKey 或长期公开 URL。对象必须属于当前配置的桶、地域与前缀。
