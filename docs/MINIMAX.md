# MiniMax 短剧配音

在 **模型与连接 → 生成策略 → 声音与字幕** 选择“独立配音 · 兼容云接口”，配音服务选 **MiniMax · 短剧配音**。界面预填官方地址和默认模型 `speech-2.8-turbo`；填 API Key、保存生成策略，即可读取账号可用音色并试音。需要启用“允许付费渠道”。保存密钥、读取目录不会提交语音生成。

## 接口及密钥

使用同步 `POST https://api.minimaxi.com/v1/t2a_v2`，Bearer Key 鉴权；可选 `speech-2.8-turbo` 和 `speech-2.8-hd`。请求采用 `stream=false`、`output_format=hex`，解码 `data.audio` 后验证 MP3。音频为单声道、32 kHz、128 kbps，记录模型、角色、声线、trace ID 和供应商返回的 `usage_characters` 等数字用量；结果保持待审核。

Key 保存在忽略提交的 `.local/settings.json`（0600），读取仅返回 `configured`；留空保留原 Key。MiniMax 地址固定，拒绝改向其他 Origin，不携带密钥跟随重定向。供应商错误正文和含密钥的参数校验输入不回显。

## 角色与逐镜试音

项目右上方 **角色配音** 可为人物或旁白选声线、语速（0.5–2）、音高（-12–12）、音量（大于 0 且不超过 10）和情绪（自动或七种基本情绪）。不提供 speech-2.8 不支持的低语选项。起始音色 ID 来自官方列表，保存 Key 后可读取系统音色及本地已确认激活的音色；其他复刻和文生音色会被过滤，避免首次使用费用。

给每镜指定一个说话者；未指定时用全局默认声线。同镜多人对白需先拆分。“生成试音”以角色第一句原台词提交一个真实配音任务，会产生 MiniMax 用量，生成后仍需听审。

改变角色声线使相关配音及成片失效，已批准剧本和视觉素材保留；更换 Key 不影响已完成音轨。修改规范或分镜仍按原规则使下游失效；编辑分镜计划会清空角色配音绑定。

任务快照保存完整已批准生产 Markdown、分镜、角色配音表、实际声音参数和逐镜参考绑定。MiniMax TTS 只接收原台词和支持的声音参数；规范不会被当作台词朗读，参考视频不会自动上传为克隆输入。音色匹配、表演、口型与声画仍需审核。

## 错误与恢复

同时检查 HTTP 和 `base_resp.status_code`，HTTP 200 的业务错误也会停止。超时、重定向、格式异常、缺失或未完成音频标记为结果需核对，不自动重发。成功返回后先保存私有回执再验证，校验失败或重启可复用回执，避免再次付费。审核或声线在请求期间变化时保留回执，阻止旧结果覆盖新配置。

接口异常保留 HTTP 状态码，以及响应头中格式受限且不含密钥的追踪编号，用于核对供应商记录；不保存原始错误正文。`1008` 明确提示 API 账户余额不足。同步接口未提供按旧请求查询音频的公开入口；没有收到音频回执时，最近调用时间不能证明生成成功或扣费。旧任务不会因后来接口恢复而被自动重新提交。

独立配音纳入合成依赖和逐镜审核。音频长于分镜时合成停止，不自动加速、截断或修改定稿台词。

## 价格和验证

2026-10-28 核对的按量价格为 Turbo **2 元 / 万计费字符**，HD 为 3.5 元 / 万计费字符。一个汉字按两个计费字符计，字母、标点、空格等各计一个。实际以接口 `usage_characters` 和供应商账单为准。选择已有自定义音色不代表工作台已实现音色设计或复刻流程。

**音色设计和快速复刻另有首次音色费，当前为 9.90 元 / 个，在首次用于合成时收取；设计接口试听另计字符费用。** 创建时没有立即收取音色费不代表免费。已激活的同一音色按当前规则不重复收取首次音色费，新台词仍计字符费。

## 固定音色资源库

长期制作规则：**不再新增定制、设计、克隆或激活其他自定义音色**。当前已支付并锁定的三个音色可以继续复用；以后新增角色只选择免音色费的系统音色或已有录音。未在官方系统目录或已激活资源库确认的 ID 在提交前拦截；本机音色目录只显示系统音色及已激活音色。系统目录缓存只接受 `system_voice` 类别，复刻/文生类别不会被当成免费系统音色。MiniMax 请求适配器禁止设计和克隆接口。“免费音色”指免音色费，TTS 字符费仍按实际调用另计。

栗栗使用已有猫叫，中文台词是字幕语义。角色供音方式设为 **已有录音 / 猫叫，不调用 TTS**（`source: "recording"`）后，工作台只复用或导入逐镜音轨，生成按钮停用，服务端也拒绝为其提交 TTS；不再使用儿童声朗读中文。

**素材库 → 固定音色资源库**保存跨项目复用的音色 ID、推荐参数和已有试听。播放试听、保存绑定与下载备份都是本地操作，不生成音频。音色条目为只读，工作台不提供覆盖、删除、重新设计或复刻接口；音色 ID 与首次使用回执绑定，音频听审状态另行保留，入库不等于批准配音质量。

项目 **角色配音 → 复用资源库音色**选择条目后，保存 `library_id` 与原 `voice_id`。声线 ID 为只读，服务端拒绝不一致的 ID；实际 MiniMax 请求只发送原 ID 和可调整的语速、音高、音量、情绪，资源库标识保留在任务快照。保存角色绑定会使受影响的旧配音与成片失效，保留已批准的规范、分镜和视觉素材。跨集重新绑定，不自动改写新分镜的说话者。

条目和试听存于忽略提交的 `.local/voice-library/`，SQLite 保存全局索引，独立于项目版本。**备份音色资源库**下载包含记录、首次计费回执、完整原生产快照与参考绑定、试听及 SHA-256 的 ZIP；不包含 API Key。备份保存使用记录，不能导出或转移 MiniMax 的模型权重。使用原 MiniMax 账号；若供应商拒绝原音色，工作台停止，不自动新建替代音色。

现有已激活音色可通过本地维护命令导入，不调用外网：`uv run python scripts/import_voices.py .local/voice-manifest.json`。私有清单含 `voices` 数组，每项为 `name`、`profile`、`preview`（相对清单的音频路径）、`receipt`（含 `usage_voice_count: 1` 与 `trace_id` 的首次回执）、`provenance`（完整生产快照与参考绑定的 JSON 或其相对路径）、`source_project_id`、`source_role_id`。相同记录重复导入复用原条目；覆盖被拒绝。命令还写入 `.local/voice-library/locked-voices-backup.zip`。恢复时将 ZIP 内记录映射回同一清单并导入原试听，保持原音色 ID，不重新设计。

测试使用明确标注的离线协议响应和依赖图夹具，不消耗真实额度，不代表已实测 MiniMax 音质、账号权限或成功率。填入真实 Key 后，通过角色试音验证实际效果。
