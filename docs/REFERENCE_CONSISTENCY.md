# 强制参考规范

所有项目默认启用资产一致性约束，无需手写配置：每个角色、场景、道具和产品先建立母版。首张可从已批准规范生成，或上传已有原图；人工确认后锁定，之后始终传递同一母版的实际文件，不因新候选产生而替换。已有项目优先使用当前版本最早批准的独立原图。缺少批准母版时，剧情关键帧停止。

上传新的标准原图并批准后，可通过“设为后续生成母版”明确替换；派生图不能成为母版。切换增加被选母版的审核版本，使旧派生图及关键帧、视频失效，切回旧母版也不会恢复旧审核。规范或分镜修改后，母版绑定失效，需按新版本重新确认素材。已排队的旧版图片任务缺少逐资产检查快照时会停止，需创建新任务。

每张生成图携带已批准 Markdown 全文、资产固定设定、项目完整资产目录及参考文件清单。视觉模型必须返回十项整体检查（身份、服装、场景、道具、左右/空间、连续性、构图、剧情、完整规范、资产覆盖），并对每个绑定资产分别返回身份、外观、剧情状态和空间四项。漏资产、漏项、额外 ID 或跳过必检项均停止。未通过或不确定时，把具体问题和修正建议加入下轮提示词，保持规范、母版及参考绑定不变。

派生参考图及关键帧质检通过后自动批准（`review_method: automatic_visual_qc`）；首次生成母版仍待人工确认，用户上传图也仍需审核。人工标记返工会自动安排修正，累积审核意见，并沿用该图剩余生成次数和已预留费用。默认最多 3 次，设置可改为 1–5 次；达到次数或预算上限、质检不可用、结果不完整或提交结果不明时停止。失败候选仅保留在任务详情，不作为合格素材。锁定母版本身被否决时，先确认或选择新的原图，不允许从文字悄悄重定身份。

需要强制多视角的项目，还可在完整制作规范中包含一个 `frameweave-reference-policy` JSON 代码块；加入后随全文修订、哈希和审批生效。不得以修改配置绕过规范审批。

示例仅使用离线演示资产，实际规则必须精确覆盖分镜中的全部资产 ID：

````markdown
```frameweave-reference-policy
{"version":1,"assets":{"hero":{"required_roles":["front","side","full_body"],"shot_roles":["front","full_body"]},"street":{"required_roles":["wide","spatial"],"shot_roles":["wide"]}},"continuity":"previous_shot","max_references":9}
```
````

`required_roles` 第一项为母版，角色必须是 `front`。母版须独立导入并人工批准；其他必备视角始终直接绑定该母版，不能用前次派生图继续漂移。`shot_roles` 必须包含母版，角色至少绑定两个不同视角。重复视角名、未覆盖资产、类型不匹配及不完整规则均拒绝。

每个视角采用当前规范、当前分镜版本下的最新候选；新的待审或返工版本不能偷偷退回旧批准版本。母版替换、来源审核版本变化使旧派生视角失效。上传或生成参考时指定 `reference_role`；不指定生成视角时选择下一待补视角，已有待审候选则停止重复提交。严格项目禁止通过重新分类补齐视角。图片角色、机位或内容是否正确仍由人审决定。

关键帧请求必须满足本镜涉及资产的全部必备视角已批准且源自当前母版；用相同字节重复上传冒充不同视角会被拒绝。自动绑定指定 `shot_roles` 及同集紧邻上一镜的已批准关键帧，第一镜不跨集引用。可以添加同一资产其他有效视角，不能跳镜、跨集或绑定其他身份。上一镜关键帧用于身份与空间参考，不等同视频尾帧；动作和物件变化按分镜入出状态执行，实际视频接点另行检查。

同一角色的多个绑定视角在本地合为参考卡，完整保留每张视图，不裁切，按格等比缩放并标注视角。合卡不调用模型。角色卡和独立场景、道具、前镜文件合计不超过 `max_references`（最多 9），为视觉质检的候选保留一个附件位置；超过则停止，不能截断参考。原始文件 ID、角色、视角、SHA-256、审核版本在任务快照中保存；运行时另存实际上传文件顺序、原始来源及参考卡哈希。提交与接收结果前重新验证依赖和字节，渠道无法接收真实参考时不能降级为文字生图。

工作台“身份与素材”显示逐视角缺口与审批入口。严格项目停用批量素材生成；母版批准后，自动生产依次补齐缺失派生视角，质检通过后继续。待审上传图、失败或缺少母版会停止。所有项目逐镜生成，同集前镜须批准后再创建下一镜任务。规范修订后，可先批准规范，再通过“按新规范复核并批准现有蓝图”明确复核保留分镜；接口要求精确当前 `contract_hash`。此操作不重写剧情、台词或角色声音绑定，也不恢复旧图片审批。

这些约束保证输入有来源、缺口会停止。文件哈希不能判断两张不同编码的图片是否同一视角，参考卡也不能从正面推断未见毛纹。自动视觉质检仍可能误判；人工可复核并否决自动批准结果，触发返工。视频目前以已批准关键帧约束生成，仍需人工审核，尚无逐帧视觉质检与自动修复。离线测试不证明真实模型的身份保持能力。
