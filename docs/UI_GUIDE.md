# 工作台使用指南

第一次使用，打开“模型与连接”，按清单连接账号并选择制作模型。之后回到“创作概览”，新建项目，导入小说或填写完整的视频需求。在项目中开启“全自动完成 · 不设费用上限”，系统会继续制作、检查和返工，完成后提供成片下载。

全自动授权只适用于当前项目。人物、场景和物品沿用固定参考，检查不合格时继续返工；不能为了继续制作而跳过一致性检查。供应商提交结果不明、账号缺失或原声音不可用时，会说明原因并停下等待处理。

## 这五个页面分别做什么

| 页面 | 适合什么时候打开 | 可以直接做什么 |
| --- | --- | --- |
| 创作概览 | 开始一个作品，或看看今天的进度 | 填写需求、查看正在制作/需要处理的作品、找到已有成片 |
| 我的项目 | 找回之前的作品 | 按状态筛选、搜索名称、继续制作、打开成片、下载作品包 |
| 素材库 | 找视频、图片、配音和录音 | 筛选项目和素材类型、预览、下载原文件；另一个分类查看已保存的角色声音 |
| 生成队列 | 看系统正在做什么，或排查卡住的步骤 | 看到实际项目和镜头名称、处理说明、任务详情及打开所属项目 |
| 模型与连接 | 首次使用，或账号和模型需要调整 | 按清单连接账号、选择四种制作能力、保存设置；需要时配置备份或检查服务 |

## 我的项目：看状态和下一步

- **正在制作**：包含排队、执行和系统自动重试。打开项目查看实时进度。
- **需要处理**：打开项目查看原因和处理办法。
- **已有成片**：全部目标集数已有当前版本、检查通过的成片。打开后播放或下载，也可下载作品包。
- **待继续**：尚未完成，包括等待确认方案、待检查或未开启自动制作。
- **已暂停或停止**：查看已完成内容，或在项目中恢复。

进度条按当前已规划的制作项计算，规划和镜头数量变化后也会变化，并非剩余时间估计。生成成功和检查通过分别记录；过期或未通过检查的视频不算可交付成片。

## 素材库：先找到整集成片

点击“下载最终成片”，只看当前版本且检查通过的整集视频。“镜头画面”是一个镜头开始时的静态图，“镜头视频”是单个片段，“最终成片”是拼接好的整集视频。点击图片或视频预览，卡片下方可直接下载原文件。

可以按项目、名称、类型和检查状态筛选。需要查旧文件时勾选“包含过期版本”；旧文件保留预览和下载，不能直接用于当前制作。历史导入项目保留原有的用途、分集和来源筛选。

“已保存的角色声音”单独展示原音色库、已有试听和本地备份。不会因浏览或播放而重新生成或激活音色。现有三个人声和猫叫录音继续按原绑定复用；新增角色使用系统音色或已有录音，新台词的 TTS 字符费另计。

## 生成队列：先看是否需要你操作

**等待自动重试**表示系统会继续，不需要再点重试；**步骤已完成**表示这一步成功，整集视频仍需后续合成。需要处理时，先看“现在需要做什么”，再打开所属项目处理。

默认隐藏已经有后续重试的旧失败记录，避免把已解决的问题一直显示成待处理；勾选“显示以前的重试记录”可查看历史。技术编号、时间和完整提示词在任务详情中展开。

提交结果不明时，“重试”会禁用。先到供应商查看原任务和账单，确认是否已有结果，再决定后续操作。不要把结果不明当作确定失败。

## 模型与连接：照清单配置

1. **连接你自己的账号**：打开“账号与连接”，添加或检查已有平台账号。凭据保存后不回显。
2. **选择四种制作能力**：分别点击“写故事和分镜”“画人物、场景和镜头”“检查画面是否一致”“把画面做成视频”，展开对应配置。先选一个模型，备用模型按需添加。检查画面的模型必须支持图片输入。
3. **保存并开始制作**：修改后点击“立即保存”或“保存生成策略”，回到项目开始。全自动费用授权在项目内开启；全局付费开关用于逐步制作。

“已填配置”只说明已有配置，不证明账号有效或生成成功。连接检查和实际任务才会发现权限、额度或接口能力问题。切换设置分类、检查账号时保留尚未保存的模型草稿；离开设置页前请保存。

声音和字幕在“生成策略”下方；尝试次数和逐步制作预算、Seedream 备用配置默认收起。“云端存储”是可选备份，默认文件仍保存在本机；“服务与更新”和扩展控制台用于排查或高级设置。

## 完整规则（全站默认，可修改）

进入 **模型与连接 → 完整规则**，查看固定流水线顺序、当前规则修订，以及各项当前值和用户文档默认值。模型分流、参考视频上限、任务查询、TTS 后置混音、BGM 音量、ASS 字幕、弹幕轨道、时间轴越界策略、FFmpeg 编码和分组计费价格都在此设置。完整原文可展开编辑；文字是规划上下文，具体执行参数需同步修改表单。

点击 **保存完整规则** 才会生效；**恢复全部默认值** 先恢复草稿，再保存。切换设置分类保留规则草稿，刷新或离开设置会丢失。保存规则变更会暂停自动项目，并使相关旧任务及输出需要重新创建或复核；不会自动产生新的付费请求。确认新规则后在项目恢复制作。固定声线、猫叫和密钥不随恢复默认重置。接口能力上限不能放宽，任务结果不明不得自动重投。

**分集分镜 → BGM、音效与弹幕时间轴** 可编辑本集后期配置；默认无 BGM、无音效、无弹幕。BGM 与音效引用同项目已批准音频的素材 ID，弹幕填 start/duration/text/color。修改后须重新批准分镜。每镜编辑可填写台词开始和结束秒数（镜头内），默认覆盖整镜。最终素材详情显示超时截断/丢弃、弹幕延后、静音异常候选，以及供应商返回的积分和按配置价格估算的费用。没有真实返回的数据一律显示未知。

### 新增远程 API 配置

- 写故事和分镜：点击“添加豆包方舟 · API Key”，填写已开通的模型 ID / 推理接入点 ID 和方舟 Key，保存。
- 声音设置：选择“火山引擎 TTS · 系统音色”，填写 Key、资源 ID，选择支持的系统声线。当前已锁定三个人声继续使用原供应商，猫叫继续使用已有录音。
- 声音设置下的“腾讯云内容安全”：填写独立 CAM SecretId/SecretKey、BizType、地域并启用。先开通 TMS/IMS/VMS；仅 Pass 放行，Review/Block 会停止任务。密钥留空保留，勾选可清除。
- 视频只允许腾讯 TokenHub Vidu；删除旧的其他视频渠道。COS 启用后，中间音轨、原始拼接视频和 ASS 文件随成片备份。

保存配置不代表账号权限或实际生成已验证；本次实现没有调用真实付费生成服务。
