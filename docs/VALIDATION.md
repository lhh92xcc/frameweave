# 验证记录

本轮验证日期：2026-10-26。开发机为 Apple Silicon macOS；容器运行时为 OrbStack。测试数据为仓库内明确标记的合成图、FFmpeg 测试片与示例小说。

## 已验证的路径

- 后端自动测试：规范审批与修订冲突、规范全文和哈希进入提示词、改动后下游失效、章节覆盖/分集时长/素材绑定校验、六类模板、队列幂等和重启恢复、暂停/取消、设置密钥不回显、项目 ZIP 不含设置。
- 模型协议测试：模拟网页额度耗尽与付费开关、云模型兜底、每个文字子调用的独立幂等键、异步任务恢复、未知提交阻止重复请求、云回执重处理、下载重试保留原任务、下载 CDN 不接收 API Key。
- 真实编排测试：使用确定性的模拟模型响应执行规范草案 → 批准 → 大纲 → 分镜；错误时长触发 JSON 修复；长篇逐段读取及多层摘要归并。
- 上游真实代码：章节解析器、FFprobe validator、字幕序列化与 FFmpegVideoRenderer 的验证/音轨混合/输出探测。没有用替代解析器冒充集成。
- 实际媒体合成：单镜/多镜 MP4、中文字幕烧录、9:16 / 16:9 / 1:1 输出、原片音频保留及独立音轨混合、过短镜头和损坏媒体拒绝。
- 浏览器自动测试：真实界面新建与导入 → 批准规范 → 分镜编辑与批准 → 上传/审核参考图 → 上传关键帧和视频 → 真实分集合成 → 成片审核 → ZIP 导出；模型设置及连接器目录；390px 手机导航与无横向溢出。人为延迟项目刷新，验证保存分镜后立即审批使用新版本，旧轮询不会覆盖刷新结果。
- 原生三个进程启动和工作台健康检查；OrbStack 镜像构建、Compose 启动和网关/引擎/worker 就绪检查。
- 上游升级：在当前固定版本实际执行 `update web2api-web`，完成依赖安装、前端构建和后端验证。独立临时 Git 仓库测试实际新提交升级与失败回滚，防止安装阶段意外重置新 pin。

## 外部模型的验证边界

本轮没有配置或使用用户真实的网页账号/API Key，没有消费用户付费额度，也没有把本地测试片称为 AI 生成样片。网页平台真实登录、额度、风控、具体模型对参考图/音频的支持及最终画质，需用户配置后逐个实测。

制作规范以完整 Markdown、修订号和哈希锁入请求，实际参考文件沿依赖传递，变更使下游审核失效。这些机制保证输入与审核可追溯；模型是否在像素、人物、动作、口型和语言上完全遵守规范，仍由人工预览和审核确认。

长篇会逐段读取并压缩为制作摘要；摘要的忠实度仍需审阅。当前是个人本地单 worker，不是多用户云服务。视频模型的支持时长和分辨率各异，不兼容的请求会显示失败，不会伪造成功结果。

## 适配层中的兼容处理

固定的引擎版本在字幕过滤器前插入空过滤器，并把画布固定为竖屏。`services/renderer.py` 继承上游渲染器，仅接管命令组装，使用正确画幅、直接切镜和有效字幕过滤器；保留其输入校验、字幕处理、音轨混合、输出探测及结果结构。分镜较多时，音轨分批使用上游规则验证。两个上游目录保持未修改状态。

原生 macOS 使用含 libass 的 `ffmpeg-full`；容器安装 FFmpeg 与 Noto CJK 字体。字幕按镜头时间段显示，尚未承诺逐字强制对齐。Edge TTS 的外部服务可用性未在本轮调用验证。
